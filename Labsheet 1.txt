20. Reverse a Number Using a Loop
Program:
void main() {
  int number = 1234;
  int reverse = 0;

  while (number > 0) {
    int digit = number % 10;
    reverse = reverse * 10 + digit;
    number ~/= 10;
  }

  print("Reversed Number: $reverse");
}
Output:
Reversed Number: 4321
Explanation: The % operator extracts the last digit, while ~/ performs integer division to remove it.

22. Check Whether a Number Is Prime
Program:
void main() {
  int number = 7;
  bool isPrime = number >= 2;

  for (int i = 2; i * i <= number; i++) {
    if (number % i == 0) {
      isPrime = false;
      break;
    }
  }

  if (isPrime) {
    print("$number is a Prime Number");
  } else {
    print("$number is not a Prime Number");
  }
}
Output:
7 is a Prime Number

24. Find the Largest and Smallest Numbers in a List
Program:
void main() {
  List<int> numbers = [10, 5, 25, 2, 18];

  int largest = numbers[0];
  int smallest = numbers[0];

  for (int number in numbers) {
    if (number > largest) {
      largest = number;
    }

    if (number < smallest) {
      smallest = number;
    }
  }

  print("Largest Number: $largest");
  print("Smallest Number: $smallest");
}
Output:
Largest Number: 25
Smallest Number: 2
25. Student Result Program in Dart
Aim: To store a student's name and marks in three subjects, calculate total marks and percentage, and display the result as Pass or Fail.
Program:
void main() {
  String name = "Rahul";

  int subject1 = 75;
  int subject2 = 80;
  int subject3 = 65;

  int total = subject1 + subject2 + subject3;
  double percentage = total / 3;

  print("Student Name: $name");
  print("Subject 1 Marks: $subject1");
  print("Subject 2 Marks: $subject2");
  print("Subject 3 Marks: $subject3");
  print("Total Marks: $total");
  print("Percentage: ${percentage.toStringAsFixed(2)}%");

  if (subject1 >= 33 &&
      subject2 >= 33 &&
      subject3 >= 33) {
    print("Result: Pass");
  } else {
    print("Result: Fail");
  }
}
Output:
Student Name: Rahul
Subject 1 Marks: 75
Subject 2 Marks: 80
Subject 3 Marks: 65
Total Marks: 220
Percentage: 73.33%
Result: Pass
Explanation:
The program stores the student's name and marks in three subjects.
It calculates total marks by adding the three subject marks.
It calculates the percentage by dividing the total by 3, assuming each subject is out of 100.
The student passes if all three subject marks are at least 33; otherwise, the result is Fail. This is an example passing rule.
